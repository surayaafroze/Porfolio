# Suraya Afroze - MERN Stack Developer Portfolio

Welcome to my personal portfolio repository! This web application showcases my projects, skills, education, and experience as a MERN Stack Developer.

## 🚀 Features

- **Modern & Premium UI**: Built with Next.js 16 (App Router), React 19, and Tailwind CSS v4.
- **Fluid Motion & Animations**: Enhanced with Framer Motion, GSAP, and Lenis smooth scrolling.
- **Dark/Light Mode**: Full theme customization using `next-themes`.
- **Interactive Projects Showcase**: Detailed views and direct links to live demos and GitHub repositories.
- **Direct Resume Download**: Convenient resume download button available across header and hero sections.
- **Contact Integration**: Easy communication via email and direct phone links.

## 🛠️ Tech Stack

- **Frontend**: Next.js 16, React 19, Tailwind CSS v4, Lucide React Icons
- **Animation**: Framer Motion, GSAP, Lenis
- **Backend & Database**: Node.js, Express.js, MongoDB
- **Deployment**: Vercel

## 💻 Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
